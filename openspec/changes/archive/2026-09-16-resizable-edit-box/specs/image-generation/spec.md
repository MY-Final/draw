## MODIFIED Requirements

### Requirement: 编辑历史 Prompt
系统 SHALL 在编辑历史 Prompt 时创建新的生成事件(以新 prompt 加原参数与参考图),不得先修改原生成记录;生成进行中时历史 Prompt 编辑入口 SHALL 禁用。编辑框 SHALL 默认随内容自动增高(上限约为视口高度的 80%),并 SHALL 提供把手供用户手动调整高度;手动调整后该高度 SHALL 在本次编辑内优先于自动增高,重新进入编辑时 SHALL 复位为自动增高。

#### Scenario: 编辑创建新事件
- **WHEN** 用户编辑某条历史 prompt 并保存
- **THEN** 系统以新 prompt 与原参数、参考图创建一条新的生成事件,原事件保持不变

#### Scenario: 生成中禁用编辑
- **WHEN** 有生成正在进行
- **THEN** 历史 prompt 的编辑入口处于禁用状态

#### Scenario: 编辑框随内容自适应
- **WHEN** 用户进入编辑且 prompt 内容较多
- **THEN** 编辑框高度随内容增长,最高约 80% 视口高,超出部分在框内滚动

#### Scenario: 拖拽把手调整高度
- **WHEN** 用户按住编辑框把手并上下拖动
- **THEN** 编辑框高度随拖动改变,并被限制在保底高度与约 80% 视口高之间,此后不再随内容自动增高

#### Scenario: 键盘调整高度
- **WHEN** 把手获得焦点且用户按 `↑` 或 `↓`
- **THEN** 编辑框高度相应增减

#### Scenario: 重新进入复位
- **WHEN** 用户取消编辑或重新进入编辑
- **THEN** 编辑框高度复位为随内容自适应
